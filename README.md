# Cusp of Discovery — Clipperton Island Web Application

Welcome to the official repository for **Cusp of Discovery**, an interactive and educational web platform exploring Clipperton Island's unique biodiversity, geography, and history.

##  Repository Structure
* `/src` — Application source code (HTML, CSS, JavaScript, assets).
* `/tests` — Unit, integration, and acceptance tests.
* `/docs` — Project documentation, wireframes, and design specs.
* `/.github/workflows` — CI/CD deployment pipeline configuration.

##  Technical Stack
* **Frontend:** HTML5, CSS3, JavaScript (Leaflet.js for interactive map)
* **Version Control:** GitHub with feature branch workflow & PR approvals
* **Hosting:** GitHub Pages / Vercel
